# Source policy and checkpoint boundary

Verified snapshot date: 10 September 2026.

## Authoritative sources

1. [ELTE IK BSc Thesis consultations - deadlines 2024](https://www.inf.elte.hu/dstore/document/227123/BSc%20Thesis%20consultations%20-%20deadlines%202024%20.pdf) requires software architecture, business rules, and a class diagram at checkpoint 3, plus registration for the Thesis Consultation subject.
2. [Assessment Criteria for BSc Theses at ELTE IK](https://www.inf.elte.hu/dstore/document/227115/thesis_assessment.docx) calibrates what a later assessable solution plan contains. Do not assign its points here.
3. [Gregory Morse's academic homepage](https://grm.web.elte.hu/) under **Supervision -> BSc Thesis Workflow Guidance** supplies the design-page, figure, traceability, and exam-topic expectations.

Use no other source to create ELTE or supervisor process requirements. External technical sources may verify a student's claims.

## Precedence and freshness

- Current binding ELTE rule precedes supervisor convention.
- Official checkpoint description precedes final-thesis criteria.
- Specific stage guidance precedes general advice.
- An explicit, evidenced supervisor-approved exception applies only to that student.
- If a live source materially changed, use the current applicable text and disclose the change.
- Never treat a generic architecture best practice as an ELTE pass gate unless one of the sources above supports it.

## Exam-topic transition

The 2026 supervisor snapshot says early final-exam topic integration may be strongly recommended rather than mandatory for the then-current transitional semester, but becomes mandatory for final submission in coming semesters. It also says selected topics should be reflected in design now.

Before using missing topic integration as a checkpoint-3 blocker:

1. determine the audited semester;
2. check the current supervisor wording;
3. apply any evidenced transitional exception.

Under an applicable transition, report missing finalized topics as a major non-blocking warning, while still requiring enough provisional planning to show the design can support suitable topics. Outside that transition, require exactly three selected topics and credible planned coverage.

## Assessment boundary

Return checkpoint sufficiency and deadline status only. Do not issue a consultation-course grade, 0-30 score, predicted grade, or defense-support decision. A thin design that would be unassessable later can fail this checkpoint; merely not being excellent cannot.

## AI and integrity

Check current point-of-use disclosure for AI-generated diagrams or text when applicable. Verify technical correspondence instead of guessing authorship. Do not use AI detectors.
