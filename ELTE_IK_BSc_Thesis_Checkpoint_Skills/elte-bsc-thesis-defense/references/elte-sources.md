# ELTE sources and decision rules

Read this reference when checking requirements. Re-open relevant live sources for the student's programme, curriculum, language, specialization and exam period; these links are starting points, not frozen regulations.

## Authority

1. Applicable current ELTE university/faculty regulations and programme-specific final-exam instructions. A current official Neptun/faculty notice supplied by the student can establish their actual sitting, assigned committee and time limit more precisely than a generic public page.
2. Current official programme pages, forms, subject catalogs and committee rosters.
3. Gregory Morse's supervision guidance and templates. These may add supervisor expectations where compatible with ELTE rules.
4. Earlier prompts, committee profiles, student reports and model defaults.

Resolve differences by applicability, date and authority, not domain name alone: grm.web.elte.hu is the supervisor's guidance, not faculty regulation. If two applicable official sources conflict materially, ask for the student's sitting-specific notice and label the unresolved point; do not silently choose. A student preference cannot waive an official limit.

Record relevant source title, URL or supplied notice identifier, stated update/effective date if visible, access date, applicable scope and the decision supported. Do not infer a rule's effective date from a crawl date or file timestamp. Reuse this record in the deliverable where it helps verify requirements.

- BSc committee guide: https://grm.web.elte.hu/supervision/BScExamCommittee.md
- MSc committee guide: https://grm.web.elte.hu/supervision/MScExamCommittee.md

For a viewer URL such as https://grm.web.elte.hu/md-viewer.html?file=supervision%2FBScExamCommittee.md&lang=en, URL-decode the file parameter and resolve it relative to the site to read the underlying Markdown. If the viewer only returns "Loading document", it has not supplied the document. Use the direct Markdown URL above or read the rendered page with available browser tools.

Read the whole relevant section, including dated corrections and addenda. The MSc committee guide contains historical material followed by a later correction covering multiple specializations; its old roster and exam-format claims must not override the correction or a student's current assignment.

The website's checkpoint, subject-selection and final-audit skills are optional complementary tools. Reuse their existing reports if supplied. These proposal/defense skills work independently; do not require another skill, a full thesis audit or a new subject-selection exercise to finish the requested task.

## When access is limited

Try an accessible official language version, linked document or supplied notice. If browsing is unavailable, use supplied material and the bundled guidance, name the verification limit, and mark unverified requirements as provisional. Never claim to have checked a source you could not read. Request only the missing excerpt or notice that materially affects the result; continue work that does not depend on it.
