Title: AI-Assisted Discovery of Dynamic Graph Algorithms via Evolutionary Code Repair

Problem & Goal

Designing correct dynamic graph algorithms, where a structural property (BFS tree, DFS tree, SCC decomposition) must be maintained incrementally under edge insertions and deletions, is error-prone and underserved by existing tooling. Recent LLM-driven evolutionary systems (FunSearch, AlphaEvolve) have discovered novel algorithms in combinatorics and numerical computation, but no tool targets dynamic graph algorithms specifically. This thesis builds a research tool that combines AI-driven code repair with exhaustive isomorphism-aware verification to assist algorithm designers in developing correct and efficient dynamic graph algorithms on directed graphs.

Proposed System

A Python-based research platform with a UI that orchestrates an evolutionary loop: candidate algorithms are generated and repaired by cooperative AI agents, tested exhaustively against all non-isomorphic digraphs (enumerated via nauty's geng + directg), and scored on correctness and efficiency relative to full offline recomputation. The system supports a tiered difficulty progression from calibration problems (dynamic BFS/DFS) through open problems (dynamic LBFS with partition refinement).

Core Contributions

1. Research tool UI framework: An interactive platform managing the evolutionary population of candidate algorithms, visualizing generation history, failure patterns, and efficiency metrics, and allowing the user to steer the search. Completion signal: the UI can launch, monitor, and replay a multi-generation evolutionary run end-to-end.

2. Isomorphism-aware dynamic graph verification engine: An exhaustive correctness checker that enumerates all non-isomorphic digraphs up to size n (via nauty), applies every possible edge operation, and compares the candidate's incremental output against offline recomputation. Completion signal: the engine correctly validates known-good algorithms (Yang et al. DFS) and rejects known-bad mutations with zero false negatives on n <= 5.

3. Custom cooperative agents with optional dynamic agent generation: A set of domain-specialized AI agents that perform code repair via structured failure reflection, with the system optionally generating new specialized agents when existing ones plateau. Completion signal: the agent system produces a correct dynamic BFS algorithm within a bounded number of generations without human intervention.

Deliverables & Requirements

Executable research tool with UI, source code, documentation, and an experimental evaluation of the system on a tiered set of dynamic graph problems with analysis of results (positive or negative). Prerequisites: graph theory (DFS/BFS properties, edge classification), evolutionary algorithms, LLM prompting. Classification: mixed (research + engineering).
