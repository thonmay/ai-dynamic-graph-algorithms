## FAILURE_DESCRIPTION
Case: n=2, root 0, initial graph [[0,0],[0,0]] (no edges). Operation: insert (0,1).
Expected after the update: parent = {0: None, 1: 0}, distances = {0: 0, 1: 1}.
Actual returned: parent = [None, None], distances = [0, -1] (vertex 1 left unreachable).
The new edge (0,1) makes vertex 1 reachable at distance 1, but the state was returned unchanged.

## ROOT_CAUSE
In `insert_edge`, the guard that decides whether to run the local BFS is:

    if dist[u] != -1 and dist[u] + 1 < dist[v]:

`dist` uses -1 for unreachable vertices. When the new edge (u,v) makes a
previously unreachable vertex v reachable, `dist[v] == -1`, so the condition
evaluates to `dist[u] + 1 < -1`, which is False for any reachable u (dist[u] >= 0).
The bounded BFS `_bfs_bounded` is therefore never called, and v (and any vertex
reachable only through v) is never marked reachable. The docstring even says the
intent is "if v is unreachable, make v reachable", but the code does not implement
that branch.

Trace on the failing case: init gives dist=[0,-1], parent=[None,None].
insert_edge(0,1): adj[0][1]=1, then check `dist[0] != -1 and dist[0]+1 < dist[1]`
-> `0 != -1 and 1 < -1` -> False. No BFS runs; state returned with dist[1]=-1.

## REPAIR_HINTS
Two coordinated changes are needed in the insertion path:

1. Fix the guard in `insert_edge` to treat -1 as infinity:
       dv = dist[v] if dist[v] != -1 else INF
       if dist[u] != -1 and dist[u] + 1 < dv:
   (equivalently `if dist[u] != -1 and (dist[v] == -1 or dist[u] + 1 < dist[v])`).

2. Fix the start-distance bug in `_bfs_bounded` for the insertion path. As written,
   when `new_dist[start] == -1` it sets `new_dist[start] = 0` and
   `new_parent[start] = None` — that would make v the root (distance 0), which is
   wrong: v's new distance must be dist[u]+1 with parent u. Smallest fix: in
   `insert_edge`, before calling `_bfs_bounded`, pre-seed the copy with
   `dist[v] = dist[u] + 1; parent[v] = u` (pass a copy so the old state is not
   mutated), so the bounded BFS only propagates improvements to v's descendants.
   Alternatively, pass the start's distance/parent explicitly to `_bfs_bounded`.

Approaches that will not work:
- Fixing only the guard without the start-distance fix: v would get distance 0
  and parent None, violating the invariant (v is not the root).
- Rebuilding the whole BFS on every insertion: correct but defeats the research
  goal of avoiding full recomputation.
