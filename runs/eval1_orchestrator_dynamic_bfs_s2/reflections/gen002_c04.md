## REPAIR_HINTS
The core bug: in `insert_edge`, when `dist[v] == -1` (v was unreachable),
the "subtree" is just {v}, and the re-discovery BFS is restricted to
`in_sub`, so newly-reachable vertices outside the old tree subtree are
never discovered. The discovery branch `if y in in_sub and dist[y] == -1`
must also allow discovering vertices that are currently unreachable
(dist[y] == -1) even when they are not in `in_sub` — i.e., the condition
should be `if dist[y] == -1` (discover any unreachable neighbor), not
`if y in in_sub and dist[y] == -1`.

Concretely, in the first BFS loop of `insert_edge`:
```python
for y in adj[x]:
    if y in in_sub and dist[y] == -1:
        ...
```
change to:
```python
for y in adj[x]:
    if dist[y] == -1:
        dist[y] = dx + 1
        parent[y] = x
        children[x].add(y)
        q.append(y)
```
This lets the BFS discover previously-unreachable vertices (like 2) that
become reachable through the newly inserted edge. The `in_sub` restriction
was meant to prevent disturbing vertices whose distances are unchanged,
but unreachable vertices (dist == -1) have no distance to preserve, so
discovering them is always safe and necessary.

Also note: the elif branch (`y not in in_sub and dist[y] != -1 and
dist[y] + 1 < dist[x]`) re-parents x to an outside vertex y, which is
correct for the "v was reachable and got shorter" case, but it can create
a cycle in the children structure if x is an ancestor of y in the old
tree — worth checking, though not the cause of this failure.

Approaches that will NOT work:
- Keeping the `y in in_sub` guard and instead expanding `in_sub` to
  include all currently-unreachable vertices: this would make the reset
  loop (`for x in subtree: if x != v: parent[x] = None; dist[x] = -1`)
  wipe out nothing (unreachable vertices already have parent None, dist
  -1), but the BFS would then be allowed to discover them. This is
  equivalent to the fix above but more convoluted; the simple fix is to
  drop the `in_sub` guard from the discovery condition.
- Running a full BFS from the root after every insertion: correct but
  defeats the purpose of the dynamic algorithm (the research goal is to
  avoid full recomputation).
