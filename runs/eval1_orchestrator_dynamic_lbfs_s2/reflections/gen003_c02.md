## ROOT_CAUSE

The missing case is `d == a`: when `a` itself is adjacent to `b` and non-adjacent to `c`, the obligation is satisfied by `a` itself.

Responsible lines in `_certify`:
```python
prefix = P[i]                      # positions < i  (strictly before a)
...
if (nb & ~bs[cc] & prefix) == 0:
    return False
```
`prefix` never contains `a` itself, so the check `(nb & ~bs[cc] & prefix) == 0` can return False even though `a` is a valid witness.
