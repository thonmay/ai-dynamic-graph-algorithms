The (LB) property (Corneil–Krueger) for a valid LexBFS ordering is:
for all positions a < b < c with **ab in E and ac not in E**, there exists d < a with **db in E and dc not in E**.

The candidate's `_is_valid_lexbfs` instead checks:
```python

    continue  # ab in E, skip
...

```
i.e. it only checks triples with **ab NOT in E and ac in E** — the exact opposite premise. This is the (LB) property for the *reverse* ordering (or equivalently, a property that is trivially satisfied by many non-LexBFS orderings).
