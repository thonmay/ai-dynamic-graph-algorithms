\texttt{NFR-PERF-01} A final grade of one BFS or DFS candidate on the full bound
($n \le 5$) completes in a bounded, predictable time. & About 10 minutes per
candidate; the re-grade of the kept candidates passed all 4,187,856 cases. \\
\addlinespace[2pt]

\texttt{NFR-PERF-02} A final-grade chunk stays within the sandbox memory limit. &
A 1,000-graph chunk at $n = 5$ peaks near 620 MB resident and returns about 50 MB
of JSON, inside the 4 GB address-space limit. \\
\addlinespace[2pt]

\texttt{NFR-SEC-01} Candidate code is isolated from the host, the network, and
the verifier's secrets. & A namespace jail with the network down, a read-only
tree, hidden host data, and rlimits (4 GB address space, CPU = timeout + 5 s, 4
tasks, 16 MB per file, 64 open files, 256 MB result); negative tests cover
network, secrets, filesystem escape, and resource exhaustion. \\
\addlinespace[2pt]

\texttt{NFR-SEC-02} Secrets are passed only by environment-variable name, never
by value, and never written to code, configuration, or logs. & The configuration
stores \texttt{api\_key\_env} (a name); the key is read from the environment at
call time; agent options and API error text are checked to drop secrets
(\texttt{test\_agent\_options\_never\_leak\_keys},
\texttt{test\_api\_error\_text\_drops\_response\_body}). \\
\addlinespace[2pt]

\texttt{NFR-SEC-03} The web UI is reachable only on the loopback address and
only with the access token. & The server binds to 127.0.0.1 by default; every API
request and websocket needs the token (HttpOnly cookie or bearer); non-local
browser Origins are refused
(\texttt{test\_cross\_site\_origin\_refused}). \\
\addlinespace[2pt]

\texttt{NFR-REL-01} A run survives interruption and resumes without losing
completed work. & A checkpoint is written every generation; resume reloads the
latest complete checkpoint, restores specialist state, and reseeds selection
(\texttt{test\_resume\_keeps\_call\_count},
\texttt{test\_resume\_draws\_the\_same\_selection\_stream}); a crash while the
marker moves keeps the last commit
(\texttt{test\_commit\_marker\_is\_replaced\_atomically\_and\_fsynced}); a verifier worker the
kernel kills does not end the verification
(\texttt{test\_dead\_worker\_falls\_back\_to\_the\_serial\_result}). \\
\addlinespace[2pt]

\texttt{NFR-REL-02} Transient model-call failures do not abort a run. & The API
backend retries a failed request up to 3 times; a call that still fails is recorded
as one failed call and the loop continues. \\
\addlinespace[2pt]

\texttt{NFR-REPR-01} The verification universe and parent selection are
reproducible; the model sampling is not. & The test universe is deterministic
across calls and the relabels are seeded
(\texttt{test\_universe\_deterministic\_across\_calls},
\texttt{test\_relabel\_determinism}); parent selection is reseeded per generation.
LLM sampling is \emph{not} seeded, so two runs with the same configuration do
\emph{not} produce identical fitness trajectories. \\
\addlinespace[2pt]

\texttt{NFR-USAB-01} The UI is usable by keyboard and carries screen-reader
labels. & Semantic controls with ARIA roles and labels and focus management are
present in the components; full WCAG conformance requires manual testing with
assistive technology and is not asserted by the automated suite. \\
\addlinespace[2pt]

\texttt{NFR-PORT-01} The tool runs on a stated platform and interpreter. & Linux
(for the namespace jail) and Python 3.11 or later; the sandbox fails closed on a
host without user namespaces. \\
\addlinespace[2pt]

\texttt{NFR-MAINT-01} The behaviour is covered by an automated test suite. & 198
pytest tests (193 fast, 5 marked slow) over the engine, verifier, sandbox,
harness, and UI server, plus 15 vitest cases over the UI state, new-run form, and
status derivation; the suite is the regression gate for every requirement above. \\
\bottomrule
\end{longtable}
